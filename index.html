Безпечні осінні канікули

Виберіть вікову категорію — і весь ресурс (правила, тест, чекліст, матеріали для батьків та пам’ятка для друку) автоматично адаптується до ваших учнів.

🔄 Що адаптується до вибраної категорії

  • 🛡️Правила безпеки — розширені, з мінною безпекою.
  • 🧩Інтерактивний тест — 6 ситуаційних запитань для кожної категорії.
  • ✅Чекліст готовності — окремі твердження для самоперевірки учнів.
  • 👪Матеріали для батьків — як підтримати самостійність дитини.
  • 🖨️Пам’ятка для друку — один аркуш A4 (книжковий формат) з вибраною категорією.
